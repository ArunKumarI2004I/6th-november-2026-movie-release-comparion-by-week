# 🎬 Indian Film Box Office Data Analysis

## 📌 Project Overview

This project analyzes and compares the Indian box-office performance of three films:

- **Ramayana: Part 1**
- **Scene**
- **Mookuthi Amman 2**

The objective is to explore box-office trends, audience occupancy, theatre show counts, and revenue performance using data analytics and interactive visualizations.

The analysis focuses exclusively on the **Indian market** to maintain consistency across all three films.

## 🎯 Project Objectives

- Compare the box-office performance of different films.
- Analyze daily India Net and India Gross collections.
- Track theatre occupancy and number of shows.
- Evaluate day-over-day box-office changes.
- Compare first-week box-office performance.
- Identify trends and differences in commercial performance.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Data visualization and dashboard development.
- **Microsoft Excel / CSV** – Dataset preparation and organization.
- **DAX** – Calculated measures and KPI development.

## 📊 Dataset Structure

The dataset contains the following fields:

| Column | Description |
|---|---|
| Movie | Film title |
| Date | Collection date |
| Day | Number of days since release |
| India_Net | Net box-office collection in India |
| India_Gross | Gross box-office collection in India |
| Overseas_Gross | Overseas box-office collection |
| Worldwide_Gross | Worldwide box-office collection |
| Shows | Number of theatrical shows |
| Occupancy | Percentage of occupied seats |
| Source | Data reference/source |

**Note:** Box-office figures are estimates and may be provisional. Unavailable values are kept blank rather than being treated as zero. Actual release dates are preserved.

## 📈 Key Performance Indicators (KPIs)

The project examines several important performance indicators:

- India Net Collection
- India Gross Collection
- Overseas Gross Collection
- Worldwide Gross Collection
- Theatre Shows
- Occupancy Percentage
- Day-over-Day Collection Changes
- First-Week Box Office Collection

## 📉 Analysis & Visualizations

The Power BI report explores:

1. **Box Office Performance:** Comparison of daily collections across the selected films.
2. **Revenue Trends:** Tracking collection changes throughout the theatrical run.
3. **Audience Occupancy:** Examining audience turnout through occupancy percentages.
4. **Theatre Shows:** Understanding the relationship between show counts and collections.
5. **First-Week Comparison:** Evaluating the opening seven days of each film.
6. **Daily Performance:** Identifying changes in collections from one day to the next.

## 🏆 Key Observation

Ramayana: Part 1 recorded an estimated **₹511.10 crore India Net collection in its first seven days**, making it a standout performer in the analysis.

The project uses this comparison to explore how different films perform across daily collections, occupancy, and theatrical distribution.
